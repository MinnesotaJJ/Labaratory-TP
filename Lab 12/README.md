# Лабораторная работа №12: Аутентификация и работа с токенами (JWT, OAuth): вход/выход пользователя, хранение сессии

В архиве собраны **3 полноценных веб-приложения** (по одному заданию с каждого уровня сложности) с разделением фронтенда (`HTML/CSS/JS`) и серверного бэкенда (`Node.js + Express`), реализующие все обязательные требования, творческие дополнения и тестовые сценарии.

## Структура проекта

1. `1_basic_variant_1_student_cabinet/` — **Базовый уровень (Вариант №1)**:
   - *Задание:* Форма входа в личный кабинет студента: логин, пароль, ошибки, кнопка выхода.
   - *Реализация:* Серверная сессия (`Map`), криптостойкий `sid` в защищенной cookie (`HttpOnly; SameSite=Strict`), хранение паролей в виде `scrypt`-хешей с солью, защита от горизонтального доступа (`403 Forbidden`), таймер обратного отсчета сессии и журнал аудита входов.
   - *Порт:* `http://localhost:3001`

2. `2_medium_variant_15_jwt_demo/` — **Средний уровень (Вариант №15)**:
   - *Задание:* JWT-демо: сервер выдает короткоживущий JWT, защищенный endpoint проверяет подпись и срок.
   - *Реализация:* Подпись `HMAC-SHA256`, строгая проверка заголовка `alg === "HS256"` (защита от `alg: none`), проверка подписи через `crypto.timingSafeEqual`, проверка claims (`exp`, `iss`, `aud`), черный список отозванных токенов (`jti` blacklist) при выходе, хранение токена исключительно в оперативной памяти клиента (защита от XSS), проверка ролей (`403`) и кнопка демонстрации подделки payload (`401`).
   - *Порт:* `http://localhost:3002`

3. `3_advanced_variant_17_jwt_rotation/` — **Повышенный уровень (Вариант №17)**:
   - *Задание:* JWT с обновлением сессии: короткий access token, безопасная ротация refresh token и выход.
   - *Реализация:* Двухтокенная архитектура: короткоживущий `Access Token` (20 сек) в памяти + одноразовый `Refresh Token` в `HttpOnly` cookie, прозрачная авто-ротация при `401 ACCESS_EXPIRED`, восстановление сессии после перезагрузки страницы (`F5`), механизм обнаружения повторного использования (`Refresh Token Reuse Detection`) с отзывом всего семейства токенов (`403`) и журнал ротации на сервере.
   - *Порт:* `http://localhost:3003`

## Инструкция по запуску в VS Code

Откройте терминал в папке нужного варианта, установите зависимости и запустите сервер:

```bash
cd 1_basic_variant_1_student_cabinet
npm install
npm start
```
После запуска откройте в браузере адрес, указанный в консоли (`http://localhost:3001`, `3002` или `3003`).
